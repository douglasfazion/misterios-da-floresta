# Arte e animação — JOCA v0.4.4

- Fonte visual: `art-source/v0.4.4-eight-frame/source-8poses.png`.
- Atlas jogável: `public/assets/joca-walk.png`.
- Oito poses organizadas em 4 colunas × 2 linhas.
- Cada célula do atlas mede 560 × 560 px.
- A preparação só recorta e reposiciona os desenhos para alinhar cabeça/tronco e a linha de apoio dos pés.
- Não houve rigging, interpolação ou redesenho dos quadros.


O arquivo-fonte recebido possui 1774×887 px. A preparação usa o último pixel de alfa relevante de cada recorte para alinhar a base; não garante, por si, que todos os contatos dos pés sejam biomecanicamente corretos. Os oito desenhos continuam intactos dentro do atlas, apenas transladados.
